# In-group neural alignment serves as a biomarker of social identity 
**Authors**: Yohay Zvi¹*, Nitai Kerem¹, Eldad Aviv² and Yaara Yeshurun¹,²*

**Affiliations**: ¹Sagol School of Neuroscience, ²School of Psychological Sciences, Tel Aviv University

## Overview
This repository contains the code used for the Intersubject Correlation (ISC), Support Vector Machine (SVM) classification analyses, text analysis, and the statistical results of the behavioral data from the paper “In-group neural alignment serves as a biomarker of social identity” (accepted for publication in PNAS, DOI pending).

## Data availability

- Raw fMRI data (including anatomical images) will be available soon on OpenNeuro.

- Preprocessed fMRI data and behavioral data are available in the following OSF repository: OSF repository ↗ (http://tiny.cc/OSF_repo).
