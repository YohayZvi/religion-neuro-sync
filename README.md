# You Are What You Sync: Neural Synchronization Predicts Religious Affiliation
**Authors**: Yohay Zvi¹*, Nitai Kerem¹, and Yaara Yeshurun¹,²*
**Affiliations**: ¹Sagol School of Neuroscience, ²School of Psychological Sciences, Tel Aviv University

## Overview
This repository contains the code used for the Intersubject Correlation (ISC) and Support Vector Machine (SVM) classification analyses, as well as the statistical results of the behavioral data.

**Note**:
Behavioral and neuroimaging data will be made available in an OSF repository upon acceptance.
